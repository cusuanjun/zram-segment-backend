# 第一批实现记录：后端模块骨架

本批仅实现生命周期和基础元数据定义，不是可用的压缩下沉功能。
设计草案中的其余接口与状态协议仍未实现。

## 改动
- 新增 zram_backend.c/.h：owner key、逻辑位置、记录/segment 元数据草图，
  空上下文的创建和销毁。尚无记录分配、引用计数、I/O 或 GC。
- 新增默认关闭的 CONFIG_ZRAM_SEGMENT_BACKEND，依赖 ZRAM_WRITEBACK。
- Kbuild 按开关链接 zram_backend.o；现有 Bazel gs_soc_sources 的 glob 包含新增文件。
- zram_meta_alloc 在池创建后初始化后端；失败时销毁池和槽位表。
- zram_meta_free 在释放槽位后销毁上下文，覆盖正常 reset 与压缩器创建失败路径。
- 不改变槽位 union、ZRAM_WB 含义、现有写回格式、读取、释放或统计语义。

## 给构建方的检查项
使用实际设备目标原有构建命令；此包未提供完整环境，不能据此给出通用编译命令。
1. 保持新配置关闭，验证原有配置的编译。
2. 启用 ZRAM_WRITEBACK 和 ZRAM_SEGMENT_BACKEND，确认新对象参与链接。
3. 如果目标支持，检查 ZRAM_GS=m 与内建组合。
4. 检查 WRITEBACK 关闭时后端开关不可选，stub 路径无未定义引用。

启用后也不会开始压缩下沉；这只用于检查本批基础设施。
